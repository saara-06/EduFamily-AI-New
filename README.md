# EduFamily AI

**An AI-powered education companion for students and families.**

🔗 **Live Demo:** https://dainty-scone-7b3868.netlify.app

## About the Project

EduFamily AI is a web-based platform designed to help students and families manage educational progress, plan budgets, explore career opportunities, and receive AI-powered guidance through Hira AI.

## Key Features

- **Family Dashboard:** A central place to view education-related information.
- **Student Progress:** Track learning progress, skills, and study goals.
- **Education Budget:** Organize education expenses and available budgets.
- **Scholarships & Careers:** Record scholarship opportunities and career goals.
- **Family Goals:** Organize family education goals.
- **Ask Hira AI:** Get AI-generated guidance about learning, education, and career planning.

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **AI Integration:** OpenRouter API
- **Frontend Hosting:** Netlify
- **Backend Hosting:** Render
- **Version Control:** Git and GitHub

## How It Works

1. Open the live application.
2. Explore the student progress, education budget, scholarship, and family goal sections.
3. Use Ask Hira AI to request educational or career guidance.
4. Save and review information through the available dashboard features.

## Important Note

Scholarship and budget entries may contain sample data. Scholarship information should be verified through official sources before applying. AI-generated guidance should be reviewed before making important decisions.
